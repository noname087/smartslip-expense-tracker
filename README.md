# SmartSlip Expense Tracker (ระบบบันทึกรายรับ-รายจ่าย & สแกนใบเสร็จ OCR)

เว็บแอปพลิเคชันสำหรับบันทึกรายรับ-รายจ่ายส่วนบุคคล พร้อมระบบอ่านตัวเลขยอดรวมสุทธิและชื่อร้านค้าจากใบเสร็จอัตโนมัติด้วย **Tesseract.js (OCR ภาษาไทย + อังกฤษ)** ประมวลผลในเบราว์เซอร์โดยตรงโดยไม่ต้องใช้ API Key

## ฟีเจอร์หลัก
- **สแกนใบเสร็จอัจฉริยะ (Receipt OCR):** อัปโหลดรูปใบเสร็จเพื่อดึง **ยอดรวมสุทธิ** และ **ชื่อร้านค้า** (บันทึกลงช่องหมายเหตุอัตโนมัติ) พร้อมปุ่มสร้างใบเสร็จตัวอย่างเพื่อทดสอบระบบได้ทันที
- **แดชบอร์ดสรุปผลรายเดือน:** กราฟสัดส่วนรายจ่ายแยกตามหมวดหมู่ (Doughnut Chart) และกราฟแนวโน้มรายรับ-รายจ่ายรายวัน (Bar Chart)
- **ระบบตั้งงบประมาณและแจ้งเตือน:** กำหนดงบประมาณรายจ่ายแยกตามหมวดหมู่ พร้อมแบนเนอร์และป้ายแจ้งเตือนเมื่อใช้จ่ายใกล้เต็มงบ (≥80%) หรือเกินงบที่ตั้งไว้ (>100%)
- **หมวดหมู่มาตรฐานและเพิ่มหมวดหมู่เองได้:** มาพร้อมหมวดหมู่มาตรฐานและฟอร์มสร้างหมวดหมู่ใหม่ (กำหนดชื่อ ไอคอน สี และงบประมาณรายเดือนได้เอง)
- **นำเข้าและส่งออกไฟล์ CSV:** รองรับการ Export และ Import ไฟล์ `.csv` เข้ารหัส UTF-8 BOM เปิดใน Microsoft Excel ได้โดยภาษาไทยไม่เพี้ยน

## วิธีใช้งาน
1. เปิดไฟล์ `index.html` (หรือ `expense_tracker.html`) บนเว็บเบราว์เซอร์ได้ทันที
2. หรือเปิดใช้งานผ่าน **GitHub Pages** โดยไปที่เมนู `Settings` > `Pages` ของ Repository แล้วเลือก Branch `main` (โฟลเดอร์ `/ (root)`)
