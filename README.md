# SmartSlip Expense Tracker (ระบบบันทึกรายรับ-รายจ่าย, สแกนใบเสร็จ OCR & ซิงค์ Google Sheets แบบเรียลไทม์)

เว็บแอปพลิเคชันสำหรับบันทึกรายรับ-รายจ่ายส่วนบุคคล พร้อมระบบอ่านตัวเลขยอดรวมสุทธิและชื่อร้านค้าจากใบเสร็จอัตโนมัติด้วย **Tesseract.js (OCR ภาษาไทย + อังกฤษ)** และระบบส่งข้อมูลไปบันทึกลง **Google Sheets แบบเรียลไทม์** ผ่าน Google Apps Script Web App

## ฟีเจอร์หลัก
- **⚡ เชื่อมต่อ Google Sheets แบบเรียลไทม์:** ส่งข้อมูลบันทึกลงในสเปรดชีต Google Sheets อัตโนมัติทันทีที่กดบันทึกรายการ พร้อมปุ่มซิงค์ข้อมูลย้อนหลังทั้งหมด
- **📷 สแกนใบเสร็จอัจฉริยะ (Receipt OCR):** อัปโหลดรูปใบเสร็จเพื่อดึง **ยอดรวมสุทธิ** และ **ชื่อร้านค้า** (บันทึกลงช่องหมายเหตุอัตโนมัติ) พร้อมปุ่มสร้างใบเสร็จตัวอย่างเพื่อทดสอบระบบได้ทันที
- **📊 แดชบอร์ดสรุปผลรายเดือน:** กราฟสัดส่วนรายจ่ายแยกตามหมวดหมู่ (Doughnut Chart) และกราฟแนวโน้มรายรับ-รายจ่ายรายวัน (Bar Chart)
- **🎯 ระบบตั้งงบประมาณและแจ้งเตือน:** กำหนดงบประมาณรายจ่ายแยกตามหมวดหมู่ พร้อมแบนเนอร์และป้ายแจ้งเตือนเมื่อใช้จ่ายใกล้เต็มงบ (≥80%) หรือเกินงบที่ตั้งไว้ (>100%)
- **🏷️ หมวดหมู่มาตรฐานและเพิ่มหมวดหมู่เองได้:** มาพร้อมหมวดหมู่มาตรฐานและฟอร์มสร้างหมวดหมู่ใหม่ (กำหนดชื่อ ไอคอน สี และงบประมาณรายเดือนได้เอง)
- **📁 นำเข้าและส่งออกไฟล์ CSV:** รองรับการ Export และ Import ไฟล์ `.csv` เข้ารหัส UTF-8 BOM เปิดใน Microsoft Excel ได้โดยภาษาไทยไม่เพี้ยน

## การติดตั้งใช้งาน Google Sheets Real-time Sync
1. เปิด Google Sheet สำหรับเก็บข้อมูล
2. ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. คัดลอกโค้ดสคริปต์จากในหน้าต่าง "Google Sheets (ซิงค์)" ของแอปไปวาง
4. กด **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)** > เลือกประเภท **เว็บแอป (Web app)**
5. ตั้งค่า: *ผู้ที่มีสิทธิ์เข้าถึง (Who has access)* เป็น **ทุกคน (Anyone)**
6. นำ Web App URL ที่ได้มาใส่ในแอป SmartSlip แล้วกดบันทึก
